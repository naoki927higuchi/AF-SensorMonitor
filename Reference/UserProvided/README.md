## 使用箇所

- `kuro_quiet.png`（平常心の輝度を60%に落としたもの）：センサーが静かなときのヘッダー左端
- `kuro_reacting.png`（センサー暴れ）：4個以上のセンサーが同時に強く反応しているときのヘッダー左端
- `kuro_normal.png`（平常心）：表示設定画面の最下部
- アプリアイコン：角丸の内側を切り出し、アダプティブアイコンの前景（64dp、縁をぼかす）に使用。背景は縁の暗い色（`icon_colors.xml`）

ブランド素材（マスコット・アイコン）であり、将来ソースコードを公開する場合もコードのライセンスの対象に含めない（共通規約の既定のライセンス方針を参照）。
